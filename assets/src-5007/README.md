# SIP-5007
This standard is an extension of [SRC-721](../../SIPS/sip-721.md). It proposes some additional functions (`startTime`, `endTime`) to help with on-chain time management.

## Tools
* [Truffle](https://truffleframework.com/) - a development framework for Sila

## Install
```
npm install truffle -g
npm install
```

## Test
```
truffle test
```
